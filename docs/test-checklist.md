# 반죽일기 테스트 체크리스트

prd.md 5.1 기능 ID별로 직접 눌러 보며 확인하는 목록이에요. (9.3의 11-1)

- **자동**: Claude가 화면 없는 브라우저(Edge)로 눌러 보고 결과를 확인한 항목 (2026-10-30, 결과 화면은 `captures/`)
- **직접**: 실제 휴대폰에서만 확인할 수 있어서 사람이 직접 해 봐야 하는 항목
- 직접 확인한 뒤 맨 오른쪽 칸에 ✅ 또는 ❌와 메모를 적어요

## 필수 기능

| ID | 기능 | 확인 방법 | 기대 결과 | 자동 | 직접 |
| --- | --- | --- | --- | --- | --- |
| F-01 | 홈 대시보드 | 기록이 없을 때와 있을 때 홈을 열어 본다 | 이번 주 연습 횟수, 전체 기록, 약한 품목 2개, 최근 연습 3건이 기록에 맞게 바뀐다 | ✅ | |
| F-02 | 품목 목록 | 제빵/제과 탭을 누르고, 이름 검색창에 "단"을 입력한다 | 탭별로 카드가 나뉘고, 검색하면 이름에 "단"이 든 품목만 남는다 | ✅ | |
| F-03 | 품목 상세 | 품목 카드를 누른다 | 사진, 시험 시간, 반죽법, 요구 사항, 주의할 점, 완성 기준이 보이고 "목록으로"로 돌아간다 | ✅ | |
| F-04 | 배합표 계산기 | 단팥빵에서 밀가루 1000g, 개수 24개를 넣는다 | 물 480g, 이스트 70g … 앙금 960g, 합계 3,000g. 50g을 넣으면 빨간 안내와 "–" | ✅ | |
| F-04 | 계산 검증 | 교재 배합표와 계산기 결과를 품목별로 비교한다 | 모든 재료 오차 1g 이내 | | |
| F-05 | 계량 체크 | 재료를 모두 체크한다 | "계량 18/18 · 모두 계량했어요!", 버튼이 "계량 완료 · 연습 시작"으로 강조 | ✅ | |
| F-06 | 성형 영상 | 영상이 있는 품목에서 재생·0.5배속을 누른다 | 화면 안에서 재생되고 0.5배속이 켜진다. 다른 탭으로 가면 멈춘다 | ✅ (시험 영상) | 휴대폰에서 전체 화면으로 바뀌지 않는지 |
| F-07 | 공정 타이머 | 연습을 시작하고 단계를 넘겨 본다 | 시간이 있는 단계는 카운트다운, 없는 단계는 스톱워치 + "완료". 끝나면 알림 문구와 함께 다음 단계로 | ✅ | **알림음이 들리는지, 안드로이드에서 진동이 오는지** |
| F-08 | 전체 경과 시간 | 시험 시간이 지나도록 둔다 (또는 짧은 내 품목으로) | 남은 시간 막대, 시간 초과 시 빨간색 "+05:00". 시간 없는 품목은 경과 시간만 | ✅ | |
| F-10 | 연습 기록 작성 | 연습을 끝낸다 | 기록 작성 화면으로 넘어가고 걸린 시간·밀가루·개수가 채워져 있다. 별점 4개를 다 매겨야 저장된다 | ✅ | **휴대폰 카메라로 바로 찍어 올리기** |
| F-11 | 기록 갤러리 | 기록 탭에서 품목 필터를 바꾼다 | 날짜 최신순 사진 격자, 필터한 품목만 보인다. 사진을 누르면 상세 | ✅ | |
| F-12 | 기록 수정·삭제 | 기록 상세에서 수정·삭제를 누른다 | 수정 내용이 저장되고, 삭제 전에 확인 창이 뜬다 | ✅ | |
| F-17 | 필터와 배지 | 전체/실기/내 품목 필터를 누른다 | 카드에 "실기", "내 품목" 배지가 보이고 필터대로 걸러진다 | ✅ | |
| F-18 | 기본 레시피 | 품목 상세의 기본 레시피를 본다 | 기준 배합(묶음별 소계·합계)과 만드는 순서(설명·포인트·동시 진행) | ✅ | |
| F-19 | 내 품목 추가 | "+ 품목 추가"로 품목을 만든다 | 빈 칸이 있으면 "고쳐야 할 곳" 목록, 저장하면 목록에 "내 품목"으로 보이고 새로고침해도 남는다 | ✅ | 휴대폰 사진첩에서 대표 사진 올리기 |
| F-20 | 내 품목 수정·삭제 | 내 품목 상세에서 수정·삭제 | 수정이 반영되고, 삭제해도 그 품목의 기록은 "(삭제된 품목)"으로 남는다 | ✅ | |
| F-21 | 기본 품목 복사 | 기본 품목에서 "복사해서 내 품목으로 만들기" | "(내 레시피)" 이름으로 편집 화면, 고쳐도 원본은 그대로 | ✅ | |
| F-22 | 기록 직접 추가 | 기록 탭 "+ 기록 직접 추가" | 품목·날짜·걸린 시간을 넣어 저장. 오늘 이후 날짜는 막는다 | ✅ | |

## 선택 기능

| ID | 기능 | 확인 방법 | 기대 결과 | 자동 | 직접 |
| --- | --- | --- | --- | --- | --- |
| F-09 | 화면 꺼짐 방지 | 휴대폰으로 연습 모드를 켜 두고 기다린다 | "화면 꺼짐 방지 켜짐" 표시, 화면이 꺼지지 않는다 | ✅ (표시만) | **실제로 화면이 안 꺼지는지** |
| F-13 | 실패 노트 | 기록에 증상을 고르고, 같은 품목을 다시 연습한다 | 원인→해결이 보이고, 다음 연습 때 품목 상세와 연습 화면 맨 위에 지난 실패 노트 | ✅ | |
| F-14 | 약한 품목 분석 | 홈 "분석 보기" | 품목별 횟수·최근 3회 평균·추이, 약한 품목 빨간 배지 | ✅ | |
| F-15 | 시험 D-day | 설정에서 시험일을 넣는다 | 홈에 D-12처럼 보이고, 지나면 D+3 | ✅ | |
| F-16 | 데이터 백업 | 백업 내보내기 → 초기화 → 불러오기 | 내보낸 파일을 불러오면 내 품목과 기록(사진 포함)이 돌아온다. 다른 파일은 거절 | ✅ | **휴대폰에서 파일이 저장되는 위치 확인** |
| F-23 | 동시 공정 타이머 | – | 이번 범위에서는 만들지 않음 (동시 진행 메모만 표시) | – | – |

## 공통·기기

| 항목 | 확인 방법 | 기대 결과 | 자동 | 직접 |
| --- | --- | --- | --- | --- |
| 시간 다시 계산 | 연습 중 화면을 끄거나 앱을 닫았다가 몇 분 뒤 다시 연다 | 지난 시간이 정확하고, 끝난 단계는 넘어가 있다 | ✅ | **휴대폰에서 실제로** |
| 연습 중 다른 화면 | 연습 중 다른 탭으로 간다 | "연습 중 · 돌아가기" 띠가 뜬다 | ✅ | |
| 화면 크기 | 휴대폰(320·390px), 태블릿(768px), PC(1280px) | 가로로 넘치는 화면 없음, PC는 가운데 2단 | ✅ | |
| 홈 화면 추가 (PWA) | 휴대폰 브라우저 메뉴 → 홈 화면에 추가 | 앱 아이콘으로 열리고, 인터넷을 끄고 열어도 화면이 뜬다 | 등록·저장만 ✅ | **배포 후 휴대폰에서** |
| 기기 테스트 | 아이폰 사파리, 안드로이드 크롬, PC 크롬 | 화면 깨짐 없음, 영상 재생, 사진 저장 | Edge만 ✅ | **아이폰·안드로이드** |
| 입력 안전 | 이름·메모에 `<img src=x onerror=...>` 같은 글자를 넣는다 | 글자 그대로 보이고 코드로 실행되지 않는다 | ✅ | |
| 두 번 누르기 | 저장 버튼을 빠르게 두 번 누른다 | 기록·품목이 하나만 생긴다 | ✅ | |
| 사용성 테스트 | 3~5명에게 "품목 고르기 → 연습 시작 → 기록 저장"을 맡긴다 | 도움 없이 3분 안에 완료 | | **직접** |
