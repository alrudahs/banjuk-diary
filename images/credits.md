# 사진·영상 출처

직접 찍은 사진으로 바꾸기 전까지 임시로 쓰는 자유 라이선스 사진이에요. 모두 위키미디어 공용(Wikimedia Commons)에서 가져왔고, 웹용으로 크기만 줄였어요(내용 수정 없음).
직접 찍은 사진으로 바꾸면 이 표에서 해당 줄을 지우고, `data/items.json`의 `photoCredit`을 `null`로 바꿔요.

다음 그림은 이 프로젝트에서 직접 그린 **임시 그림**이에요. 일러스트레이터로 만든 그림(prd 8.1)이 생기면 같은 이름으로 덮어써요.

- `images/items/default.svg`: 사진이 없을 때 보여 주는 기본 이미지
- `images/empty.svg`: 빈 화면 일러스트
- `images/logo/icon.svg`와 `icon-512.png`·`icon-192.png`·`icon-180.png`: 앱 아이콘 (PNG는 SVG를 그대로 찍어 만든 것이라, SVG를 바꾸면 PNG도 다시 만들어요)
